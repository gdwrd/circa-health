- Motion sampling in the firmware (FW4): state at `0x20BA38` (+7 = start sampling, +8 = go back to tap-wait), per-tick handler `0x82E3F4`, read timer handle `0x20BA28`, tap-wait decision at `0x82E802` (`0x8389EC` then `0x82EA30`, both non-zero sets +8). - Ring RAM (3.00.33): app region `0x207C00`..`0x20EC00`, `.bss` ends `0x20DC30`, RAM-code overlay `0x20DC30`..`0x20DCF8` (table `0x2083D8`, loader `0x8249D8`); `0x20DCF8` and up is free until the heap at `0x20EC00` (FW6's count byte is `0x20DCF8`). Motion interrupt: the handler `0x82E884` only sets flags; the `qc_app` g-sensor poll `0x82E656` handles it and skips the sampling start while `0x20BA3B` (sampling active) is set; sampling start is `0x82D926`; register read helper for the accelerometer `0x82D57A(reg)`. Patched image packets: `A1 05` samples, `A1 07` / `A1 08` echoes, `A1 09 <count>` double tap; `A1 0A` / `A1 0B` light copy on / off, `A1 0C` light samples; `A1 0F` wear state; 0D / 0E are kept for FW8c, free sub-types start at 10. Phone link: `0x829B5E` returns 1 while link state byte `0x2099ED` is 2 (connected); `0x82A600` drops packets otherwise. The emulator fakes a dropped link with `e.ble_disconnect()`; the next `ble_write` reconnects. FW12's sample counter is 4 bytes at `0x20DD00`, FW7a's light mode byte is `0x20DD04`, so free RAM starts at `0x20DD08`; `A1 05` carries it in the low 6 bits of the first sample's three low bytes.
- Wear state (3.00.33, `docs/FIRMWARE.md` § Wear state): `0x830CAC()` returns 1 worn / 0 not worn (from `0x20BC87`); it refreshes only while the optical chip runs (each HR measurement, plus up to 6 one-a-minute checks after "not worn") and reads "worn" from boot to the first measurement and for the first second of each one. The HR log's 0 is an unwritten `0xFF` slot, never a measured value; a finished measurement under 40 bpm is logged as a random 40..49. The stock emulator always says worn (zero calibration): a "not worn" run needs a faked calibration and reflection registers.
- Firmware clock (3.00.33): the word at `0x2087B0` is seconds since 2000-01-01 in the local time `01 yy MM dd HH mm ss` sets, +60 in the minute handler `0x82576E`.
